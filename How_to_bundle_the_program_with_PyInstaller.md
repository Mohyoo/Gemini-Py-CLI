> This guide will help you bundle the program on any operating system, assuming you didn't make breaking-changes in the source code, otherwise edit steps as needed.

## Easy Way
1. First, remove your API key from 'settings.py'. It's also recommended to reset settings to default via 'settings_editor.py' (though the bundling script should auto factory-reset them).
2. Install PyInstaller if not already: `pip install pyinstaller`
3. Make sure all necessary libraries are installed: `pip install httpx google-genai prompt_toolkit rich pyperclip questionary stop_words tksvg resvg_py markdown tkinterweb json_repair html2text beautifulsoup4`
> It's better to install all libraries + PyInstaller in a virtual environment.
4. PyInstaller may fail to include some libraries, and the CLI arguments for it didn't help in my case. To fix this, create a `missing_libs` folder beside `gemini.py`, then run this command: `python -c "import os, sys, webbrowser; path = os.path.dirname(sys.executable); webbrowser.open(os.path.join(path, 'Lib'))"` and look for `site-packages` (or `dist-packages`) and go in.
5. Well, here you should've run the bundling once to know which libraries are missing, but in my case, it was `tksvg`, so I copied the two folders named `tksvg` from the `site-packages` folder to our `missing_libs` folder (You may need to copy other related files such as DLL or SO, etc.)
> Check `User_Data/application_errors.txt` for tracebacks, or start the `gemini` executable or one of its modes executables from a terminal (i.e: don't double click it, start it from terminal).
6. Now, go back to the directory where `gemini.py` and run `python bundler.py`. It should give you enough details about the rest. Once done, just check `FINAL_GEMINI` folder, and voila! that's your app.

## Headache Method (In case the bundler script failed)
1. Do all steps in the `Easy Way` except the last step.
2. Rename `settings.py` to anything, or just move it elsewhere.
> This is required because PyInstaller will try to include `settings.py` in a nested internal folder God knows where, and it'll no longer be easily modifiable. So we prevent it from including it, then we include it ourselves beside the generated executables.
3. Open the terminal from where `gemini.py` lives, and run the following commands:
```
python -m PyInstaller --onedir --contents-directory . --icon "Data/Gemini Icon.ico" gemini.py
python -m PyInstaller --onedir --contents-directory . --icon "Data/Settings Icon.ico" settings_editor.py
python -m PyInstaller --onedir --contents-directory . --icon "Data/Gemini Icon.ico" "Modes/momentary_chat.py"
python -m PyInstaller --onedir --contents-directory . --icon "Data/Gemini Icon.ico" "Modes/temporary_chat.py"
python -m PyInstaller --onedir --contents-directory . --icon "Data/Gemini Icon.ico" "Modes/image_generator.py"
python -m PyInstaller --onedir --contents-directory . --icon "Data/Gemini Icon.ico" "Modes/file_generator.py"
python -m PyInstaller --onedir --contents-directory . --icon "Data/Gemini Icon.ico" "Modes/google_searcher.py"
```
4. Rename/move back `settings.py` now.
5. Go to the generated `dist` folder, create a new folder and name it (for example) `release`. Merge `settings_editor` dir with `gemini` dir in that `release` folder (replace files when asked).
> The `release` folder should now have the executables directly.
6. In the `release` folder, create a `Modes` folder, and merge the four dirs (from the previous `dist` folder) in it:
```
momentary_chat
temporary_chat
image_generator
file_generator
google_searcher
```
> The `Modes` folder should now have the executables directly.
7. Go back to where `gemini.py` is, and copy these files & dirs:
```
gemini.py
settings.py
error_logger.py
global_logger.py
useless.py
User_Data
Modes
Data
```
8. Now go to `dist/release` folder and paste and overwrite if asked.
9. Now go back to `missing_libs` folder, and copy its content, then paste it in: `dist/release`, then paste again in `dist/release/Modes` directly.
10. Perform a quick cleanup. Go to `release` folder and delete the following folders:
```
dist
build
Modes/dist
Modes/build
User_Data (delete its content except the 'word_suggestion.txt')
* Also delete the '.spec' files generated by PyInstaller.
* Once you are sure everything is working, delete the 'dist' & 'build' folders generated by
  PyInstaller, you'll find them in the source folder beside 'gemini.py' and in `Modes` folder.
```
11. It should be done now, but optionally, do the following:
+ Add other stuff to the `release` folder, like `Licenses`, `Wiki` and `Secret` folders.
+ Save space by creating symlinks, since `dist/release` and `dist/release/Modes` are similar, ***BUT*** this will make the program un-portable and it must never be moved. If yes, go to `dist/release/Modes` dir, and run this python script in an ELEVATED terminal:
```
import os
import shutil
import platform
from pathlib import Path

system = platform.system()
if system == 'Windows':
    current_items = [item for item in os.listdir() if not item.endswith(('.exe', '.py'))]
else:
    current_items = []
    for item in os.listdir():
        if item.endswith('.py'):
            continue
        if os.path.isfile(item) and os.access(item, os.X_OK):
            continue
        current_items.append(item)

for item in current_items:
    symlink_location = Path(item)         # Where the symlink lives.
    target_location = Path('..') / item   # To where the symlink points.
    shutil.move(item, target_location)
    symlink_location.symlink_to(target_location, target_is_directory=target_location.is_dir())
```
+ Hide internal program's files and folders, so the program's dir becomes easy to navigate. Go to `release` folder and run this python script:
```
import os
import platform

system = platform.system()
if system == 'Windows':
    import ctypes
    FILE_ATTRIBUTE_HIDDEN = 0x02
    current_items = [item for item in os.listdir() if not item.endswith(('.exe', '.py', MODES_DIR, PROGRAM_DATA_DIR, 'Secret'))]
    for item in current_items:
        ctypes.windll.kernel32.SetFileAttributesW(item, FILE_ATTRIBUTE_HIDDEN)
    os.chdir(MODES_DIR)
    current_items = [item for item in os.listdir() if not item.endswith(('.exe', '.py'))]
    for item in current_items:
        ctypes.windll.kernel32.SetFileAttributesW(item, FILE_ATTRIBUTE_HIDDEN)
        
    # Create helper batch files.
    root_items = [item for item in os.listdir('..') if not item.endswith(('.exe', '.py', MODES_DIR, PROGRAM_DATA_DIR, 'Secret'))]
    modes_items = [item for item in os.listdir() if not item.endswith(('.exe', '.py'))]

    # 2. Create the HIDE batch string.
    hide_bat_content = "@echo off\n"
    hide_bat_content += f'echo Hiding...\n'
    for item in root_items:
        hide_bat_content += f'attrib +h "{item}"\n'
    hide_bat_content += f'pushd "{MODES_DIR}"\n'
    for item in modes_items:
        hide_bat_content += f'attrib +h /l "{item}"\n'
    hide_bat_content += "popd\n"

    # 3. Create the UNHIDE batch string.
    unhide_bat_content = "@echo off\n"
    unhide_bat_content += f'echo Revealing...\n'
    for item in root_items:
        unhide_bat_content += f'attrib -h "{item}"\n'
    unhide_bat_content += f'pushd "{MODES_DIR}"\n'
    for item in modes_items:
        unhide_bat_content += f'attrib -h /l "{item}"\n'
    unhide_bat_content += "popd\n"
    
    # 4. Save batch scripts.
    with open(os.path.join('..', 'Hide Internal Files.bat'), 'w', encoding='utf-8') as f:
        f.write(hide_bat_content)
    with open(os.path.join('..', 'Reveal Internal Files.bat'), 'w', encoding='utf-8') as f:
        f.write(unhide_bat_content)
        
elif system == 'Darwin':
    import subprocess
    current_items = [item for item in os.listdir() if (not item.endswith(('.py', MODES_DIR, PROGRAM_DATA_DIR, 'Secret')) or (not os.path.isfile(item) and os.access(item, os.X_OK)))]
    for item in current_items:
        subprocess.run(['chflags', 'hidden', item], check=False)
    os.chdir(MODES_DIR)
    current_items = [item for item in os.listdir() if (not item.endswith('.py') or (not os.path.isfile(item) and os.access(item, os.X_OK)))]
    for item in current_items:
        subprocess.run(['chflags', 'hidden', item], check=False)

else:     # Linux
    current_items = [item for item in os.listdir() if (not item.endswith(('.py', MODES_DIR, PROGRAM_DATA_DIR, 'Secret')) or (not os.path.isfile(item) and os.access(item, os.X_OK)))]
    with open('.hidden', 'w', encoding='utf-8') as f:
        f.write('\n'.join(current_items) + '\n')
    os.chdir(MODES_DIR)
    current_items = [item for item in os.listdir() if (not item.endswith('.py') or (not os.path.isfile(item) and os.access(item, os.X_OK)))]
    with open('.hidden', 'w', encoding='utf-8') as f:
        f.write('\n'.join(current_items) + '\n')
```
